# ليتر كرافت — مولّد خطابات التغطية

تطبيق ويب ثنائي اللغة (العربية RTL والإنجليزية LTR) لإنشاء مسودات خطابات تغطية.

## ما يفعله
- إدخال الاسم والمسمى الوظيفي والشركة والوصف الوظيفي والخبرة.
- اختيار النبرة (رسمية، ودودة، واثقة) والطول.
- إنشاء ثلاث نسخ مختلفة من الخطاب من قوالب محلية، مع إمكانية تعديل النص.
- نسخ الخطاب أو تنزيله كملف نصي، وحفظه في سجل محفوظ في التخزين المحلي.

## ملاحظة مهمة
التوليد تجريبي ويتم بالكامل على جهاز المستخدم من قوالب جاهزة. لا توجد خدمة ذكاء اصطناعي خارجية ولا يُرسل أي نص إلى خادم.

## التشغيل
```bash
npm install
npm run dev
npm run build
```
